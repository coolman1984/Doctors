# Eyada — نظام العيادات (working name)

Clinic management for Egyptian private clinics and small medical centres: works fully offline on every PC, PCs share
changes encrypted, patient data stays inside the clinic, patients' phones reach it only through an internet mailbox.
Small locked core + modules opened per customer by a signed licence. Arabic and English, light and dark.

Status: Phase 0 (study and plan). Start with `docs/PLAN.md`, `docs/MARKET_STUDY.md` (Arabic), `docs/REFERENCE_STUDY.md`.
Rules for developers and agents: `CLAUDE.md`.
